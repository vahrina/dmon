what is this?

dmon is a minimal fork of the unfortunately soon defunct myrient with following features

  • only a portion of what myrient originally provided (> 300TB)
  • no advertisements
  • no registration
  • no paywalls

is this all that's left?

no! luckily, many people are actively contributing to preseve digital history ⸜(｡˃ ᵕ ˂)⸝♡ below are several reliable sources i came across while creating this minimal version

  • official discord
  • minerva-archive.org
  • myrient.org

note about file dates

  • upload dates will differ, as wget preserves the original "last modified" timestamp, instead of the initial upload seen prior on myrient
  • original timestamps were retained where possible; apologies for any inconsistencies ;-;
